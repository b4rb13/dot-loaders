# Dotquilt

Loading experiences that occupy a predictable space while content becomes ready, then give way to that content.

## Language

**Loading surface**:
A visual indication that content is pending, including a skeleton shape, text treatment, chart silhouette, or table silhouette.
_Avoid_: Spinner as a name for every loading surface

**Skeleton**:
A placeholder that represents the shape or structure of expected content.
_Avoid_: Using skeleton as the name for every loading indicator

**Handoff**:
The change from a loading surface to its real content once that content is ready.
_Avoid_: Arrival as a second name for the same product concept

**Idle motion**:
The decorative movement of a loading surface while its content is still pending.
_Avoid_: Idle as a synonym for ready content or inactive rendering

**Pointer response**:
An optional decorative reaction of a loading surface to a nearby pointing device.
_Avoid_: Hover as a name for both decorative dot movement and functional control feedback

**Animation variant**:
A named choice of idle motion or handoff behavior for a loading surface.
_Avoid_: Preset when referring only to an animation rather than a reusable visual treatment

**Motion pack**:
A collection of animation variants designed to work together as a visual treatment.
_Avoid_: Engine feature when referring to a collection of authored animations

**Reveal target**:
An application-owned content element explicitly included in a coordinated handoff.
_Avoid_: Treating arbitrary content discovered by a selector as an opted-in reveal target

**Loading region**:
An area that coordinates a loading placeholder and its real content through a loading cycle.
_Avoid_: Loader when referring to the whole coordinated area

**Readiness**:
The application's determination that an area can present its useful outcome, including successful content, an empty result, or an error with recovery options.
_Avoid_: Treating a nonzero value or a successful request as the only ready outcome

**Refresh**:
A loading cycle in which existing content remains useful while an updated outcome is pending.
_Avoid_: Replacement when the existing content is still relevant

**Replacement**:
A loading cycle in which existing content is no longer relevant to the requested outcome.
_Avoid_: Refresh when the previous content belongs to an unrelated context

**Loading cycle**:
A single attempt to obtain and present an outcome in a loading region, whether initial loading, refresh, or replacement.
_Avoid_: Treating an appearance change as a new load

**Preset**:
A reusable visual treatment for a loading surface.
_Avoid_: Template when referring only to a visual treatment

**Template**:
A composed interface example that combines loading surfaces with a realistic content layout.
_Avoid_: Preset when referring to a whole interface composition

**Acquired version**:
A delivered version of a paid collection that a customer is entitled to keep using.
_Avoid_: Equating continued use with access to every future update

**Update window**:
The period during which a customer is entitled to released updates for a purchased collection.
_Avoid_: Treating update access as a subscription required to keep using acquired files
