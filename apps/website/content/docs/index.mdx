Use native Web Components or the thin React adapter. Start with a loading region and a few lines of skeleton text.

<section id="setup">

## Set up the private preview [#setup]

This version is not on npm. Use the reviewed private package files; a public installation command will appear after the package identity and release are verified.

1. Get the frozen core and React tarballs from your reviewed local build.
2. Open [Complete example](#complete-example) below and save each file under its shown path.
3. Place the tarballs in the example’s `vendor/` directory. Run `bun install`, `bun run build` and `bun run start`.

<section id="readiness">

## Your application owns readiness [#readiness]

Start a new `cycle` when a request begins. Set `state="pending"` to show the placeholder and `state="ready"` when your real content can be presented. Keep the same content nodes throughout.

The example uses buttons so you can inspect the two states. It doesn’t fetch data, infer readiness from a value or keep loading while you read.
