<section id="motion">

## Choose each phase independently. [#motion]

<ComponentPhases component={props.component} />

Simple skeleton factories expose pulse(\{periodMs\}) and dissolve(\{duration,fallPx\}). TypingDots has only its bounded built-in activity; use region timing for its content handoff.

Use the public defineAnimation authoring API for typed family-specific idle or handoff definitions, or definePreset for local immutable configurations. Idle supplies frame/still; handoff supplies duration, synchronous prepare and frame. Callbacks receive immutable snapshots and bounded draw/reveal commands, not a DOM/canvas context. Restrictions, cancellation and cleanup remain engine-owned. Configuration changed during a handoff applies next time; invalidated targets or geometry settle safely.

CSS controls include `--dotquilt-color`, `--dotquilt-accent-color`, `--dotquilt-dot-size`, `--dotquilt-dot-gap`, host dimensions and the exposed `::part(surface)`. Skeleton hosts also expose `--dotquilt-radius`. Reserve the real content’s space in application CSS. Fine-hover pointer lift is optional and suspended for touch, handoff and motion restrictions.

</section>
