TableLoader is Dotquilt's table skeleton loader: it holds the place of a table. Each cell shows a short bar of marks shaped like what the column holds, with a glow drifting across. When the data arrives, each cell's marks gather into the text in its place, then the rows wipe in as the marks leave.

## Usage

Describe the columns and set how many rows to show. The handoff reads your real table, so it needs nothing else.

With a `targetProvider`, the table uses the `rows` handoff instead: each cell's marks form its characters, glyph by glyph, and the rows you pass as the region's **reveal targets** settle in one after another.

## Options

| Attribute | Prop | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `rows` | `rows` | number | `5` | How many rows to show, up to 100. |
| `row-height` | `rowHeight` | number | `32` | Row height in pixels. |
| | `columns` | `{ kind, width? }[]` | three text columns | What each column holds (`text`, `number`, `badge` or `date`) and its share of the width. Up to 20. |
| `mark` | `mark` | `dot` \| `square` \| `dash` | `dot` | Dashes suit table rows well. |
| `speed` | `speed` | number | `1` | How fast the glow moves. |
| `pointer-response` | `pointerResponse` | `none` \| `lift` | `none` | `lift` lights the marks around the pointer while the placeholder shows, on devices with a fine pointer. |
| `motion` | `motion` | `system` \| `paused` | `system` | `system` follows the visitor's reduced-motion setting; `paused` stills the field. |

## Animations

Import alternatives from `dotquilt/animations/table` and pass them as `animations`.

| Phase | Default | Also available |
| --- | --- | --- |
| Idle | `tableShimmer`: still bars under a drifting glow | `typeOn`: bars grow as if being typed |
| Handoff | the marks gather into each cell's real text, then the rows wipe in | `rows` (with a `targetProvider`): cells form their characters and rows settle in 80 ms apart |

| Animation | Options (default) |
| --- | --- |
| `tableShimmer`, `typeOn` | `cadenceMs` 250–1200 (600), `cellStyle`: `auto` (from the columns), `text`, `number`, `badge`, `date`, `badge-text` or `text-badge` |
| `rows` | `staggerMs` 0–120 (80), `settlePx` 0–8 (5) |
