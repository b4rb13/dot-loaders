Skeletons hold the shape of images, text and avatars while they load. A soft glow drifts across the marks, and when the region hands over they leave from left to right.

## Usage

Put a skeleton in a region's `placeholder` slot. Size it with CSS like any other element: blocks fill their width and take the height you give them, and lines are two rows of marks tall.

<Tabs syncKey="framework">
  <TabItem label="Native">
    ```html
    <dotquilt-region state="pending" aria-label="Team member">
      <div slot="placeholder">
        <dotquilt-skeleton-circle></dotquilt-skeleton-circle>
        <dotquilt-skeleton-text lines="2" mark="dash"></dotquilt-skeleton-text>
      </div>
      <article>…</article>
    </dotquilt-region>
    ```
  </TabItem>
  <TabItem label="React">
    ```tsx
    <LoadingRegion
      state={member ? 'ready' : 'pending'}
      aria-label="Team member"
      placeholder={<SkeletonText lines={2} mark="dash" />}
    >
      <article>…</article>
    </LoadingRegion>
    ```
  </TabItem>
</Tabs>

## Elements

| Element | React | Use |
| --- | --- | --- |
| `<dotquilt-skeleton-block>` | `SkeletonBlock` | images, charts and other rectangles |
| `<dotquilt-skeleton-line>` | `SkeletonLine` | one line of text |
| `<dotquilt-skeleton-circle>` | `SkeletonCircle` | avatars and icons |
| `<dotquilt-skeleton-text>` | `SkeletonText` | a paragraph of lines |

## Options

| Attribute | Type | Default | Description |
| --- | --- | --- | --- |
| `mark` | `dot` \| `dash` \| `square` | `dot` | The shape of each mark. Dashes suit text lines; squares stay crisp at small sizes. |
| `motion` | `auto` \| `paused` | `auto` | `paused` stills the marks. Reduced motion does the same. |
| `speed` | number | `1` | How fast the idle glow moves, from above 0 up to 4. |
| `lines` | number | `3` | SkeletonText only: how many lines, up to 50. |

## Colours

The marks use a slate that sits inside any app, with a soft teal glow. Change them with custom properties:

```css
.profile {
  --dotquilt-color: #627467;
  --dotquilt-accent-color: #3f7f86;
}
```
