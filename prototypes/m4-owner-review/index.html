On every example

  1. Start loading. The previous cycle finishes first; watch one or two cycles: calm, legible, no harsh flash or obvious jump at a loop boundary.
  2. Reveal now. Placeholder departure and real content should feel like one transition. No blank gap or lingering dots.
  3. Replay the 700 ms request. Judge the default pace, not just a long idle.
  4. Enable pointer lift and move across the dots, then leave. The response should settle without shifting layout. It requires a fine pointer with hover.
  5. Refresh visible content. The existing content remains readable; it should not disappear behind a replacement placeholder.
  6. Interrupt a reveal. The new load must win, then resolve without stale content, stuck masking or duplicate terminal effects.
  7. Pause motion, then reveal. Content must remain available. Pause must survive subsequent loads until you resume.

Before approval

Long idle motion deliberately becomes still when its engine motion window expires; Start loading begins a fresh interval. Try OS reduced motion separately; compare light/dark and a narrow window.
