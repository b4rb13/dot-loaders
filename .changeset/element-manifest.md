Editors now know Dotquilt's elements. The package ships a Custom Elements Manifest (`customElements` in package.json) and JetBrains web-types (`web-types`). Together they describe every element's attributes, properties, methods, events, slots, parts and CSS custom properties. VS Code, WebStorm, Storybook and other tools read them for autocomplete and docs.
